# ランドリー出店ナビ

住所を入れると、コインランドリーを出店した場合の来店客数・月の売上の目安と、出店の判定（◎おすすめ／○検討／△慎重に）を出すWebアプリです。

- 来店客数 = 世帯数（単身・子育て世帯を多めに数える）× 来店率 × 月の利用回数。近くの他社に取られる分を距離で差し引く
- 開業1年目・2年目の目安は直営店の実績（3年目に対して約80%・約92%）から
- 「直営店の実績で合わせる」: 直営店マスタのExcelを端末内で読み、予測が実績に近づく来店率を求める（売上データは送信しない）
- 候補地の保存・比較、A4横の出店判定レポート印刷

データ: 総務省統計局「令和2年国勢調査」500mメッシュ（`data/mesh/`、`tools_convert.py` で変換）／住所検索: 国土地理院／地図・他社店舗: Google Maps Platform（`config.js` のキーは fuchi0624.github.io にリファラ制限）
